# 📊 Blinkit Retail Sales & Outlet Performance Dashboard

A clean, interactive **Power BI dashboard project** focused on understanding **how retail outlets perform, what products drive sales, and how customer engagement changes across locations and time**.

This project is designed as a **portfolio-ready business intelligence case study** that demonstrates my ability to transform raw data into **clear, decision-ready insights for stakeholders and hiring managers**.

---

## 🌟 Why This Project

Modern retail teams don’t just need reports — they need **stories backed by data**.

This dashboard helps answer key business questions like:

* Which outlet types generate the highest sales?
* How does product category and fat content impact performance?
* Which locations and tiers perform better over time?
* How visible are products, and how does that affect engagement?

The goal is to simulate a **real-world retail analytics environment** where leadership can make faster, smarter decisions.

---

## 🛠️ Tech Stack

* **Power BI Desktop** – Dashboard design and data modeling
* **DAX (Data Analysis Expressions)** – KPI creation and performance metrics
* **CSV / Excel** – Data source and preprocessing
* **Business Intelligence Principles** – Layout, UX, and insight storytelling

---

## 📈 Key Metrics Tracked

* **Total Sales** – Overall revenue performance
* **Average Sales per Item** – Sales efficiency metric
* **Number of Items Sold** – Product movement volume
* **Average Customer Rating** – Engagement and satisfaction indicator
* **Item Visibility Index** – Product exposure and placement performance

## 🚀 How to Run This Project

3. If prompted, connect the dataset from the `dataset` folder

## 📦 End-to-End Workflow

This project follows a complete **business intelligence lifecycle**:

1. **Data Collection**
   Raw retail sales data sourced from CSV/Excel files

2. **Data Cleaning & Preparation**

   * Handled missing values and data type mismatches
   * Standardized product categories and outlet classifications

3. **Data Modeling**

   * Built relationships between outlet, product, and sales tables
   * Optimized star schema for reporting performance

4. **DAX & KPI Development**

   * Created measures for Total Sales, Average Sales, Ratings, and Visibility Index
   * Implemented dynamic calculations responsive to slicers

5. **Dashboard Design (UX/UI)**

   * Business-friendly layout with executive KPI cards
   * Consistent color theme and spacing for readability

6. **Publishing & Sharing**

   * Published report to Power BI Service
   * Generated public live link for stakeholder access
   * Embedded link in GitHub portfolio
